# STR Scout

STR Scout is a Context Protocol MCP server for short-term rental market analysis.

It exposes one tool, `analyze_str_market`, which estimates annual revenue ranges, ADR, occupancy, competitive saturation, amenity gaps, and top comparable Airbnb listings for a market.

## What It Does

- Wraps Airbnb listing acquisition through Apify actors with primary/fallback scraper support.
- Caches raw listing data to reduce repeat-query latency.
- Produces structured MCP output with a strict `outputSchema`.
- Adds a short investor-facing summary generated by Gemini, with a rule-based fallback if Gemini is unavailable.

## Important Limitation

STR Scout does not use booking-partner data. Revenue and occupancy are inferred from listing prices and a review-velocity model. Results should be treated as directional market intelligence, not verified booking revenue.

## Architecture

- `src/server.ts`: Express server, MCP transport, Context auth middleware.
- `src/tools/analyzeMarket.ts`: tool handler and end-to-end analysis pipeline.
- `src/services/apify.ts`: primary/fallback scraper orchestration.
- `src/services/cache.ts`: Redis or in-memory cache layer.
- `src/services/analysis.ts`: revenue, ADR, occupancy, saturation, amenity, and comparable calculations.
- `src/tools/index.ts`: MCP tool definition and schema contract.

## Environment

Copy `.env.example` and provide:

- `APIFY_TOKEN`
- `GEMINI_API_KEY`
- `REDIS_URL` (optional)
- `PORT` (optional)
- `ENABLE_WARMUP_ENDPOINT` (optional)

`CONTEXT_API_KEY` is only required for marketplace validation scripts, not for running the server locally.

## Run Locally

```bash
pnpm install
pnpm start
```

Server endpoints:

- `GET /health`
- `POST /mcp`
- `GET /mcp`
- `DELETE /mcp`

## Validation

```bash
pnpm typecheck
pnpm test
```

Additional scripts:

- `pnpm test:marketplace`: validates the live marketplace listing through `@ctxprotocol/sdk`
- `pnpm test:analysis`: unit-style analysis checks on sample data
- `pnpm test:curious-coder`: validates primary scraper sample parsing

## Notes

- The canonical marketplace target is the live STR Scout listing already registered on Context.
- Query-mode marketplace validation requires a funded Context account with sufficient Auto Pay allowance.
- Cold markets can still take materially longer than cache hits because the upstream scrape is expensive.
